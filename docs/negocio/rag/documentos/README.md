# Documentos

Deja aquí el **archivo original**: PDFs, `.md` o `.txt` oficiales (aranceles,
reglamentos, fichas de trámites) o documentos de escenarios ya redactados.
No los abras ni los guardes como texto. Después ejecuta
`python tool/rag_ingestar_documentos.py`. Ver `docs/negocio/rag/README.md`.

`extraido/` lo genera la ingesta: es texto para leer y citar, no escenarios.
